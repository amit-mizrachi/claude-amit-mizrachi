# Obsidian master notes and the Tasks note

Each project has a **master note** in `/Users/amitmizrachi/Documents/obsidian/Amits Vault/6 - Full Notes/`, linked from [[Tasks]] (add the link under In Process / Done). It is the project's single record of plan, progress and lessons.

Sections:
1. **Overview** - project context, repo, stack
2. **Planned Work** - checkable items (`- [ ]` / `- [x]`); write the plan here before implementing, tick items as you go
3. **Lessons** - after any user correction, add the pattern; read the project's lessons when you start work

When work ends, add a review section with the results.
