# Obsidian master notes and the Tasks note

Each project has a **master note** in Obsidian, linked from [[Tasks]]. The master note is the project's single record of plan, progress and lessons.

## Where things live
- Master notes: `/Users/amitmizrachi/Documents/obsidian/Amits Vault/6 - Full Notes/`
- Task tracker: [[Tasks]] - add `[[wikilinks]]` under In Process / Done
- Cross-reference related notes with `[[wikilinks]]`

## Structure
Every master note holds three sections:
1. **Overview** - project context, repo, stack
2. **Planned Work** - checkable items (`- [ ]` / `- [x]`)
3. **Lessons** - corrections and patterns learned during work on this project

## Workflow
1. **Plan First**: write the plan to **Planned Work**
2. **Verify Plan**: check in before starting implementation
3. **Track Progress**: mark items complete as you go
4. **Explain Changes**: give a high-level summary at each step
5. **Document Results**: add a review section to the master note
6. **Capture Lessons**: after any user correction, add the pattern to **Lessons**
